# Three in 1 - Unity Final Exam  Unity 2019.4.41f2 project with a main menu and three games: - Driving Game - Flying Game - Sumo Ball  ## Controls - Esc: pause menu (Resume, Restart, Back to Main Menu)  ## How to run Open the project folder in Unity Hub (2019.4.41f2), open the MainMenu scene and press Play.
